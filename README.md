DiaBite is a modern Android application built with Kotlin and Firebase.

## Overview
This repository contains the source code for the DiaBite application. It leverages a modern tech stack to provide an intuitive user experience, integrating Firebase for real-time backend capabilities.

## Features
- **Modern UI**: Built with responsive design principles.
- **Firebase Integration**: Robust backend features utilizing Firebase.
- **Kotlin Power**: Enjoy the safe, concise, and expressive nature of Kotlin.

## Getting Started

### Prerequisites
- [Android Studio](https://developer.android.com/studio)
- JDK 17 or higher

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Roza212/DiaBite.git
   ```

2. **Open the project:**
   - Launch Android Studio.
   - Select **Open** and choose the `DiaBite` directory.

3. **Firebase Setup:**
   - This project uses Firebase. You will need to obtain the `google-services.json` file for your Firebase project and place it in the `app/` directory. (Note: This file is excluded from version control for security).

4. **Build and Run:**
   - Sync the project with Gradle files.
   - Select your target device/emulator and hit **Run**.

## Project Structure
- `app/` - Contains the main Android application code and resources.
- `functions/` - Contains Firebase Cloud Functions.
